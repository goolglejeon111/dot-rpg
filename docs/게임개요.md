# 게임 개요

> 모든 설정은 언제든 바뀔 수 있다. 바뀔 때마다 연결된 다른 설정도 함께 고친다.
> 표시: **[확정]** 정해진 것 / **[임시]** 바꿔도 부담 없는 것 / **[보류]** 나중에 정할 것

## 1. 기본 방향 [확정]

- 장르: 판타지 실시간 액션 도트 RPG, 스토리 중심
- 느낌: 쯔꾸르풍 도트, 이동은 좀비고처럼, 대화는 스탠딩 일러스트 + 대사창
- 스토리 구조: 대륙전기처럼 영웅 하나를 골라 그 영웅의 이야기를 플레이. 조연들이 파티를 구성
- 첫 영웅: 기사 레온. 다른 영웅은 이후 추가
- 엔딩 구조(페이트식)
  - 트루엔딩: 올바른 선택만 골랐을 때
  - 히든엔딩: 특정 조건을 모두 맞췄을 때
  - 배드/데드엔딩: 여러 개
  - 노말엔딩 없음
- 원칙: 무조건 전부 무료(도구, 서비스)

## 2. 개발 환경 [확정]

- 플랫폼: 웹(브라우저)
- 엔진: Phaser 3 + TypeScript + Vite
- 버전 관리: Git, GitHub
- 스토리 모드를 먼저 완성하고 멀티플레이는 나중에
  - 멀티 서버: Colyseus, Render 무료 플랜
  - 세이브는 각자 브라우저에 저장
- 나중에 Electron으로 PC 설치판 제작 가능
- 대사, 인물, 선택지, 엔딩 조건은 코드에 직접 쓰지 않고 `src/data/`에 데이터로 분리
- 인물과 지역은 이름이 아니라 고유 ID로 연결

## 3. 전투 [확정]

- 실시간 액션
- 파티 최대 4명, 파티원 전원이 필드에 등장
- 플레이어는 한 명을 조작, 버튼으로 언제든 교체. 조작하지 않는 동료는 AI로 자동 전투
- 모든 동료는 파티에 넣고 조작 가능
- 게이지가 차면 두 명 이상이 함께 쓰는 합동 기술
- 동료에게 명령 내리는 기능은 없음
- 최종전에서만 레온만 조작 가능, 나머지 전원 AI

### 튜토리얼 배치

| 장면 | 배우는 것 |
|---|---|
| 프롤로그 장면 1~3 | 레온 기본 조작(이동, 공격, 회피, 오러) |
| 1막 장면 4 | 동료 AI 전투, 캐릭터 교체 |
| 2막 장면 7 | 첫 합동 기술 |

## 4. 호감도와 관계 [확정]

| 대상 | 결과가 바뀌는 곳 |
|---|---|
| 세레나 | 5막: 대주교를 따라가는지, 레온을 택하는지 / 최종장: 피를 흘리는지 |
| 엘리시아와 레온 | 4막: 엘리시아의 선택 |
| 엘리시아와 카르크 | 4막: 엘리시아의 선택 / 최종장: 세뇌 해제 |
| 카르크 | 최종장: 자르한 늑대 부족의 합류 |
| 아드리안 | 5막: 설득 성공 여부(2막 행동 포함) |

- 엘리시아와 카르크의 관계는 두 사람이 부딪힐 때 레온(플레이어)이 고르는 **중재 선택지**로 쌓인다. 한쪽 편을 드는 것이 아니라 둘 다 존중하는 답이 정답
- 엘리시아와 세레나의 대화는 분위기를 푸는 만담. 분기에는 영향 없음

## 5. 그림 [확정]

| 종류 | 쓰이는 곳 | 비고 |
|---|---|---|
| 도트 캐릭터 | 필드 이동, 전투 | Pixelorama |
| 스탠딩 일러스트 | 대화 장면 | 고해상도. 블루 아카이브 같은 깔끔한 선과 색, 셀 셰이딩 |

- 대화 연출: 두 사람이 나란히 서고, 말하는 사람은 밝게, 듣는 사람은 어둡게
- 스탠딩은 몸 한 장 + 표정별 얼굴로 나눠 그림(기본, 웃음, 화남, 슬픔, 놀람)
- 파일은 배경 투명 PNG, 이름 규칙:

```
leon_body.png
leon_face_normal.png
leon_face_smile.png
leon_face_angry.png
leon_face_sad.png
leon_face_surprised.png
```

- 완성 전까지는 회색 실루엣 임시 그림 사용
- 제작 순서: 레온 한 명 완성 → 프롤로그에 넣어 확인 → 나머지 인물로 확장

## 6. 소리 [확정]

- 직접 만들지 않음. jsfxr(효과음), BeepBox(배경음), OpenGameArt, Freesound
- 파일은 ogg 또는 mp3만 사용
- 받은 소리는 라이선스(출처 표기 필요 여부) 확인
