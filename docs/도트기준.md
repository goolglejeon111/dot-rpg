# 도트 기준

필드 인물 도트와 맵 타일을 다시 그릴 때 따르는 기준입니다.
그림 수준과 크기만 맞추고, 다른 게임의 그림을 따라 그리지 않습니다. 인물 디자인은 `docs/캐릭터디자인.md`를 따릅니다.

- 생성기: `npm run art:hd` (`tools/pixel-art/gen-hd.mjs`)
- 비교 그림: `node tools/pixel-art/sample-hd.mjs` → `docs/도트_샘플.png`
  - 줄은 예전, 1차 샘플, 수정본 순서입니다.
  - 왼쪽 띠 색은 회색이 예전, 금색이 1차, 하늘색이 수정본입니다.
- 예전 그림: `public/assets/_old/`에 그대로 둡니다.

## 1. 팔레트

- 64색 이하입니다(`tools/pixel-art/palette.mjs`). 지금은 색 묶음 15개(63색)와 반투명 그림자 1색으로 64색을 다 씁니다. 색을 더하려면 비슷한 색을 하나 빼야 합니다.
- 색 묶음은 밝음에서 어둠 순서이고, 끝 칸은 그 색의 외곽선으로 씁니다.
- 그림자 쪽은 회색이 아니라 푸른 보라 쪽으로 기울입니다.
- 반투명 그림자 `#2a1a48` 35%는 발밑 그림자와 벽 아래 그림자 띠에 씁니다.
- 가장 어두운 칸은 짙은 남색 `#1d2735`입니다. 순수 검정에 가까운 색은 쓰지 않습니다.

| 묶음 | 쓰는 곳 |
|---|---|
| skin | 피부 |
| hair | 짙은 갈색 머리(레온). 밝은 쪽이 보이게 칠하고, 가장 어두운 칸 `#2e2425`는 외곽선·속눈썹에만 |
| navy | 근위기사 남색. 기본은 `#2e5a94`, 그림자는 `#1d3050`, 외곽선은 `#1d2735` |
| white | 흰 옷, 장갑, 은 장식·갑옷 (예전 이름 silver도 같은 묶음) |
| gold | 금 장식, 몰딩, 상감, 자수 점 |
| slate | 바지·구두, 어두운 돌 (예전 이름 black). 가장 어두운 칸도 `#1d2735` |
| red | 진홍(카펫, 세레나 눈·옷 테두리) |
| ivory | 대리석, 밝은 돌벽, 따뜻한 백금색 머리 `#e0d8d0` 계열 (예전 이름 stone, plat) |
| wood | 나무 징두리판, 받침, 가죽 |
| sky | 눈, 유리, 물 |
| green | 풀, 줄기 |
| fire | 불꽃 |
| violet | 로브, 마탑, 룬 |
| sand | 모래, 밝은 가죽 |
| ash | 회색 머리·털, 쇠, 회색 돌 (어두운 두 칸은 slate와 같은 색) |

## 2. 인물 (32x48)

- 한 칸은 32x48입니다. 발끝은 칸 아래에서 2px 위(46번째 줄)에 둡니다.
- 엔진의 기준점은 아래 가운데입니다(`footOrigin`).
- 키는 2.5~3등신이고 몸은 가늘게 그립니다. 머리 높이는 16~18px, 눈은 2x3입니다(속눈썹, 흰자·눈동자, 홍채).
- 키 차이는 머리·몸을 내려서 냅니다(인물 설정 `drop`).
  - 레온이 세레나보다 약 3px 큽니다(세레나 `drop: 3`).
- 외곽선은 검정을 쓰지 않습니다. 1px이며, 바로 안쪽 색보다 두 단계 어두운 색입니다.
  - 남색 옷의 외곽선은 짙은 남색 `#1d2735`입니다.
  - 부위(망토, 뒷머리, 다리, 몸, 어깨망토, 머리, 얼굴, 앞머리, 팔, 견장)를 따로 그려 외곽선을 넣은 뒤 겹칩니다.
- 명암은 세 단계(밝음, 바탕, 그늘)이고 반짝임 점을 1~2개 둡니다. 빛은 왼쪽 위에서 옵니다.
- 발밑 그림자는 그림에 넣지 않습니다. 엔진이 타원(18x6, 위 그림자색)으로 깝니다.

### 밝기 규칙

- 인물이 밝은 맵 위에서 혼자 어둡게 뜨지 않게 합니다.
- 옷의 기본색은 밝은 쪽 칸을 씁니다. 그림자 칸은 그늘에만 씁니다.
  - 예: 레온 제복의 기본색은 `#2e5a94`입니다. 디자인 기준의 짙은 남색 `#1d2735`는 그림자·외곽선에만 씁니다.
- 가장 어두운 옷 색도 순수 검정 근처로 내려가지 않게 합니다. 바지·구두도 `#3c4558`가 기본입니다.
- 머리카락은 디자인의 색이 보이게 칠합니다(짙은 갈색은 갈색으로 보이게). 가장 어두운 칸은 외곽선에만 씁니다.

### 디자인 지키기

- 레온의 은색 어깨 갑옷은 왼쪽 어깨 하나뿐입니다. 정면에서는 화면 오른쪽에 있습니다.
  - 가슴판은 가운데에 좁게 그려서 반대쪽 어깨와 이어져 보이지 않게 합니다.
- 세레나 드레스에는 금색 자수 점을 몇 개 찍습니다(`docs/캐릭터디자인.md`의 금색 자수).

### 걷기

- 4프레임입니다: 발 닿음 → 한 발 들고 지나감 → 반대 발 닿음 → 지나감.
- 미끄러지듯 보이지 않게 움직임을 크게 줍니다.
  - 발 닿는 프레임은 몸이 1px 내려갑니다.
  - 옆모습은 보폭 10px(뒤 발 10, 앞 발 20)이고, 지나가는 프레임에서는 무릎을 3px 듭니다.
  - 앞뒤 모습은 앞으로 나온 발이 1px 아래, 든 발이 3px 위입니다.
  - 팔은 앞뒤로 2칸 흔듭니다.
  - 망토 끝과 치맛단, 긴 머리는 걸음 반대쪽으로 1px 흔들립니다. 옆모습에서는 뒤로 2px 날립니다.

### 시트 배치 (예전과 같은 칸 순서)

- **필드** `public/assets/sprites/{id}.png`: 5열 x 8행.
  - 0~3행은 걷기입니다(서기, 걷기1~4). 방향은 아래, 왼쪽, 오른쪽, 위 순서입니다.
  - 4~7행은 점프입니다(웅크림, 뛰어오름, 꼭대기, 착지, 서기).
- **전투** `public/assets/battle/chars/{id}.png`: 48x48 칸, 12열 x 4행.
  - 인물을 (8, 2)에 놓습니다.
  - 열 순서: 공격1~3(준비·휘두름), 막기, 피격, 시전 둘, 무릎 꿇음, 쓰러짐.
- 인물 설정은 `tools/pixel-art/hd/cast.mjs`(레온·세레나는 `hd/people.mjs`)에 있습니다. `docs/캐릭터디자인.md`의 도트 포인트를 옮긴 것입니다.
  - 같은 인물의 다른 복장은 `like`로 바탕 인물을 이어받고 다른 곳만 적습니다.
  - 전투 시트는 예전에 전투 시트가 있던 인물만 만듭니다. 무기(`weapon`, 쌍검 `dual`), 돌진(`lunge`), 시전 구슬 색(`cast`)을 인물마다 정합니다.
- 새 도트로 바꾼 인물은 `src/data/explore/hd_sprites.json`에 적힙니다. 엔진은 이 목록을 보고 칸 크기, 발 위치, 머리 위 높이를 정합니다.
- 목록에 없는 인물은 예전 32x40 그대로 그려집니다.

## 3. 타일 (32x32)

- 바닥은 무늬 여러 가지를 섞어 반복이 보이지 않게 합니다.
  - 무늬 갈래는 타일 시트 맨 뒤 줄에 덧붙입니다.
  - 엔진이 칸 위치로 정해지는 난수에 따라 섞어 깝니다(40%는 기본 타일). 맵 데이터는 바꾸지 않습니다.
- 대리석 바닥:
  - 판 사이 줄(십자 줄)은 연하게 그립니다. 바탕보다 한 단계 어두운 색만 씁니다.
  - 줄 없는 한 장짜리 판 갈래를 섞어 바둑판처럼 보이지 않게 합니다.
- 판·돌 하나하나에 위·왼쪽 1px 하이라이트를 둡니다.
- 벽은 바닥보다 두 단계 어둡게 칠합니다(회색이나 따뜻한 회갈색 쪽). 벽과 바닥의 경계가 바로 읽혀야 합니다.
- 벽은 세 층입니다.
  - 윗면: 위에서 본 돌판이고, 판마다 1px 하이라이트를 둡니다.
  - 앞면 위: 엇갈린 돌벽과 금 몰딩입니다.
  - 앞면 아래: 나무 징두리판입니다. 세로 결은 드문드문 넣어 지저분해 보이지 않게 합니다.
- 반복되는 큰 무늬(카펫 마름모 등)는 두 칸마다 둡니다. 가로로 번갈아 까는 갈래는 `alternate`로 정합니다.
  - 테두리에는 작은 무늬를 넣어 한 줄 띠처럼 보이지 않게 합니다.
- 벽과 바닥이 닿는 곳에는 그림자 띠를 둡니다. 벽 바로 아래 바닥 칸 위쪽에 4px은 35%, 다음 4px은 18%로 엔진이 깝니다.
- 물건(기둥, 횃불, 깃발 등)은 타일과 따로 그립니다. 크기는 예전 물건과 같게 둡니다(`src/data/explore/sprites.json`의 w, h).
- 타일 순서·이름과 맵 구조는 바꾸지 않습니다.
- 1~4막 타일은 `tools/pixel-art/hd/world.mjs`에서 갈래(맨땅, 돌판, 벽돌, 벽 윗면, 널빤지, 물, 용암, 풀, 흙벽)로 그립니다.
  - 맨땅 얼룩은 크고 연하게 두 단계만 씁니다. 바둑판이나 마름모 모양 얼룩이 보이지 않게 합니다.
  - 돌판·벽돌 안은 고른 바탕에 티끌만 드문드문 둡니다. 점을 촘촘히 섞어 거칠게 보이게 하지 않습니다.
  - 넓게 까는 바닥(풀, 모래, 눈, 흙, 돌판 등)은 갈래를 1~2개 더 붙여 엔진이 섞어 깝니다.
  - 벽은 같은 지역 바닥보다 두 단계 어둡게 칠하고, 아래에 그림자 띠를 깝니다.

## 3-1. 다시 그리지 않은 그림

- 무늬가 특별한 타일(핏자국, 쇠창살, 결계, 구름, 부두, 수로 가장자리, 지하실 벽, 판잣집 지붕)과 황궁 밖 물건, 생물(쥐, 거머리, 모래 벌레, 전갈, 안개 짐승, 바위 도마뱀, 불 정령, 용암 민달팽이, 수로의 괴물, 용암 수호자, 아스트라 골렘), 작은 그림(상자, 집, 표지판, 나무, 말풍선 표시)은 모양을 그대로 두고 색만 새 팔레트로 옮겨 칠합니다(`hd/remap.mjs`).
  - 가장 가까운 팔레트 색으로 바꾸므로 검정에 가까운 외곽선은 짙은 남색 `#1d2735`이 됩니다.
  - 예전 그림은 `public/assets/_old/` 같은 자리에 있고, 옮겨 칠하기는 늘 이 예전 그림에서 시작합니다.
- 발밑 그림자 그림(`shadow`, `shadow_large`)은 그대로 둡니다.

## 4. 엔진

- 깊이 정렬은 발 y 기준입니다(`setDepth(y)`).
- 머리 위 표시(조사 표시, 말풍선 자리), 전투 HP바, 데미지 숫자는 인물마다 키가 커진 만큼(`rise`) 올립니다.
- 전투 판정은 바꾸지 않았습니다. 발밑 원과 몸 너비로 판정하는데, 새 도트도 너비가 같기 때문입니다.
- pixelArt와 정수 배율은 그대로입니다.
