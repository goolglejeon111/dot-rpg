# 도트 기준

필드 인물 도트와 맵 타일을 다시 그릴 때 따르는 기준입니다.
그림 수준과 크기만 맞추고, 다른 게임의 그림을 따라 그리지 않습니다. 인물 디자인은 `docs/캐릭터디자인.md`를 따릅니다.

- 생성기: `npm run art:hd` (`tools/pixel-art/gen-hd.mjs`)
- 비교 그림: `node tools/pixel-art/sample-hd.mjs` → `docs/도트_샘플.png`
- 예전 그림: `public/assets/_old/`에 그대로 둡니다.

## 1. 팔레트

- 64색입니다(`tools/pixel-art/palette.mjs`). 색 묶음 14개(63색)와 반투명 그림자 1색으로 이루어집니다.
- 색 묶음은 밝음에서 어둠 순서이고, 끝 칸은 그 색의 외곽선으로 씁니다.
- 그림자 쪽은 회색이 아니라 푸른 보라 쪽으로 기울입니다.
- 반투명 그림자 `#2a1a48` 35%는 발밑 그림자와 벽 아래 그림자 띠에 씁니다.

| 묶음 | 쓰는 곳 |
|---|---|
| skin | 피부 |
| hair | 레온 머리(짙은 갈색) |
| plat | 세레나 머리(백금색) |
| navy | 레온 제복·망토, 깃발, 창 유리 |
| silver | 은 장식, 갑옷 |
| gold | 금 장식, 몰딩, 상감 |
| white | 흰 옷, 장갑 |
| black | 바지·구두, 벽 윗면 |
| red | 진홍(카펫, 세레나 눈·옷 테두리) |
| stone | 대리석, 밝은 돌벽 |
| wood | 나무 징두리판, 받침 |
| sky | 눈, 유리 반짝임 |
| green | 풀, 줄기 |
| fire | 불꽃 |

## 2. 인물 (32x48)

- 한 칸은 32x48입니다. 발끝은 칸 아래에서 2px 위(46번째 줄)에 둡니다.
- 엔진의 기준점은 아래 가운데입니다(`footOrigin`).
- 키는 2.5~3등신이고 몸은 가늘게 그립니다. 머리 높이는 16~18px, 눈은 2x3입니다(속눈썹, 흰자·눈동자, 홍채).
- 외곽선은 검정을 쓰지 않습니다. 1px이며, 바로 안쪽 색보다 두 단계 어두운 색입니다.
  - 부위(망토, 뒷머리, 다리, 몸, 어깨망토, 머리, 얼굴, 앞머리, 팔, 견장)를 따로 그려 외곽선을 넣은 뒤 겹칩니다.
- 명암은 세 단계(밝음, 바탕, 그늘)이고 반짝임 점을 1~2개 둡니다. 빛은 왼쪽 위에서 옵니다.
- 발밑 그림자는 그림에 넣지 않습니다. 엔진이 타원(18x6, 위 그림자색)으로 깝니다.

### 시트 배치 (예전과 같은 칸 순서)

- **필드** `public/assets/sprites/{id}.png`: 5열 x 8행.
  - 0~3행은 걷기입니다(서기, 걷기1~4). 방향은 아래, 왼쪽, 오른쪽, 위 순서입니다.
  - 4~7행은 점프입니다(웅크림, 뛰어오름, 꼭대기, 착지, 서기).
- **전투** `public/assets/battle/chars/{id}.png`: 48x48 칸, 12열 x 4행.
  - 인물을 (8, 2)에 놓습니다.
  - 열 순서: 공격1~3(준비·휘두름), 막기, 피격, 시전 둘, 무릎 꿇음, 쓰러짐.
  - 문서의 "공격 3, 피격 1, 다운 1"이 이 배치에 들어 있습니다.
- 새 도트로 바꾼 인물은 `src/data/explore/hd_sprites.json`에 적힙니다. 엔진은 이 목록을 보고 칸 크기, 발 위치, 머리 위 높이를 정합니다.
- 목록에 없는 인물은 예전 32x40 그대로 그려집니다.

## 3. 타일 (32x32)

- 바닥은 무늬 2~3가지를 섞어 반복이 보이지 않게 합니다.
  - 무늬 갈래는 타일 시트 맨 뒤 줄에 덧붙입니다(`floor_b`, `floor_c`).
  - 엔진이 칸 위치로 정해지는 난수에 따라 섞어 깝니다. 맵 데이터는 바꾸지 않습니다.
- 판·돌 하나하나에 위·왼쪽 1px 하이라이트, 줄눈 앞 1px 그늘을 둡니다.
- 벽은 세 층입니다.
  - 윗면: 위에서 본 돌판이고, 판마다 1px 하이라이트를 둡니다.
  - 앞면 위: 엇갈린 돌벽과 금 몰딩입니다.
  - 앞면 아래: 나무 징두리판입니다.
- 벽과 바닥이 닿는 곳에는 그림자 띠를 둡니다. 벽 바로 아래 바닥 칸 위쪽에 4px은 35%, 다음 4px은 18%로 엔진이 깝니다.
- 물건(기둥, 횃불, 깃발 등)은 타일과 따로 그립니다. 크기는 예전 물건과 같게 둡니다(`src/data/explore/sprites.json`의 w, h).
- 타일 순서·이름과 맵 구조는 바꾸지 않습니다. 새로 그린 칸만 `palace_tiles.png`에서 바꿉니다.

## 4. 엔진

- 깊이 정렬은 발 y 기준입니다(`setDepth(y)`).
- 머리 위 표시(조사 표시, 말풍선 자리), 전투 HP바, 데미지 숫자는 인물마다 키가 커진 만큼(`rise`) 올립니다.
- 전투 판정은 바꾸지 않았습니다. 발밑 원과 몸 너비로 판정하는데, 새 도트도 너비가 같기 때문입니다.
- pixelArt와 정수 배율은 그대로입니다.
