### 5막 필요한 것 (지금 엔진 기준)

| 필요한 것 | 지금 엔진 | 더 만들어야 할 것 |

### 대본 확인 요청

- 장소 "루멘 신성국 대성당"(2막 막간, 4막 막간 성전의 깃발): 세계관은 지역과 세력을 섞지 않는다고 하는데, 세력 이름 + 건물입니다. 성도 이름이 정해지면 "○○ 대성당"으로 바꿀지 확인 부탁드립니다.
- 1막 장면 6의 첫 이동 구간(빈민가 골목, 맵 `slum_alley`) 동안 화면 왼쪽 위 장소 이름이 장면 장소 "아우렐 강 다리 검문소"로 나옵니다. 골목을 걷는 동안은 "황도 외곽 빈민가"가 맞는지 확인 부탁드립니다.
